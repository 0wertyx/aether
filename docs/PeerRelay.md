# Desktop peer relay
The Peer Relay page uses a deployed AETHER-Luau external relay over HTTPS. The operator must provision a room and individual participant tokens using the existing server API. Enter the HTTPS origin and your own participant token; opt in explicitly. The app sends only halo, wings, and their color, and displays anonymous previews of other participants. It retries transient failures and stops on invalid or expired invitations. Switching tabs or pressing Disconnect sends a best-effort leave; expiry cleans up if delivery fails. Tokens are never saved to disk by this feature.
This does not connect to Roblox, discover players, modify game state, map real accounts or render other users in public games. The in-experience RemoteEvent transport remains separate. The external server must be hosted and configured before testing.
Run npm test for helper tests, npm run build for the frontend, and npm run tauri -- dev on a system with Rust and Tauri prerequisites to test the Desktop integration.
